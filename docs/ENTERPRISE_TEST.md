## 验证结论

- **安装/卸载闭环可靠**：静默安装、完整卸载均验证通过。
- **学习模式→审计部署→重启生效**链路完整可用。
- **审计模式安全**：不拦截任何程序，仅记录，适合生产环境先行观察。
- **健康检查**能正确反映系统状态（全新安装时因无规则会报告异常，学习后恢复通过）。

## 待验证项

1. **强制模式**：风险较高（策略覆盖不完整时可能影响系统组件），建议在专用测试机或快照环境下验证，生产环境保持审计模式观察 1-2 天后再切换。
2. **审批流**：审计模式下拦截事件较少，待审批列表可能为空（正常）。
3. **多终端/集中管理**：未实现（规划 v1.0）。

## 企业版部署检查清单

### 前置条件
- [ ] Windows 10/11 **企业版 / 教育版 / Server**（家庭版/专业版不支持完整 App Control）
- [ ] 管理员权限
- [ ] 系统还原点已创建（保险）
- [ ] 已了解：强制部署可能导致部分程序无法运行

### 部署步骤
1. [ ] 复制 `WdacPlatform-Setup.exe` 到目标机
2. [ ] 右键"以管理员身份运行"（或 `/S` 静默安装）
3. [ ] 浏览器打开 `http://localhost:8765` 确认控制台
4. [ ] 点击「学习采集」，等待 1-5 分钟（事件越多越全）
5. [ ] 点击「审计部署」→ 重启系统
6. [ ] 观察 1-2 天：日常软件是否都产生审计事件、是否有拦截需求
7. [ ] 如确认无误：点击「强制部署」（先通过覆盖率检查）
8. [ ] 异常时：控制台「回滚策略」或 `Setup.exe /U` 卸载

### 测试重点观察
- 日常办公软件能否运行（审计模式应全部正常）
- 开机/登录是否正常
- 网络/打印/USB 是否正常
- 控制台「审计」页是否记录预期事件

### 异常处理
- 系统无法启动：用 Windows 恢复环境删除 `C:\Windows\System32\CodeIntegrity\SIPolicy.p7b` 后重启
- Agent 无法启动：检查 `C:\wdac-platform\logs\agent.log`
- 需要回滚：控制台「回滚策略」或 `/U` 卸载
